# Public Release Plan

The complete publishing and marketing plan lives in the repository root as `distribution_roadmap.md`.

It covers:

- A 50-commit public history plan.
- Suggested commit messages.
- File scopes per commit.
- Estimated time per commit.
- Validation per commit.
- Python and JavaScript SDK distribution.
- GitHub Action, Docker, PyPI, npm, and GitHub Pages setup.
- Launch marketing plan for stars, traffic, downloads, and early adopters.

Read it before creating the public GitHub repository.
